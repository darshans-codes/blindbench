# BlindBench design

The homepage is a calm, editorial introduction to a privacy workstation. It opens with one proposition and a concrete, clearly marked fictional histogram. The application uses a persistent study navigation on desktop and a compact collapsible menu on mobile. The overview shows the actual study inventory, supported operations and next steps.

| Token | Value |
| --- | --- |
| Canvas, surface, raised | `#0B101A`, `#141D2C`, `#202C42` |
| Ink, muted, border | `#E2E8F0`, `#94A3B8`, `#334155` |
| Protocol, verified, caution | `#A5ABFF`, `#5EEAD4`, `#FBBF24` |
| Typography | System sans and system mono, with no external font request |
| Rhythm | 4px base, 12–24px component spacing, 44px minimum main controls |

The headline, chart and navigation share the same dark canvas and indigo accent. Use teal for a verified outcome or topology labels with accessible text. Use chart bars and a readable value list. Keep the charts legible at 390px. Use visible focus rings, skip navigation, semantic headings, form error summaries and reduced-motion behavior. Leave unsupported actions out of the interaction path and explain the gated capability in its relevant screen.
